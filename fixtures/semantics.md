AST 中 table 必须有 alias；同一查询块别名唯一，别名隐藏原表名。from 是表或一个二表 inner/left join；join 使用 using 非空列名数组或 on 一个 eq，不可同时存在。using 中每个名字在两侧各唯一。未限定输出命名空间按 using 的声明次序输出合并列，再列左侧非 using 列、右侧非 using 列；合并列的值取左侧（本题没有 RIGHT/FULL JOIN）。qualified star 仍展开原侧全部列，LEFT JOIN 未匹配右侧列均为 NULL。非 using 的同名列保留两个候选，未限定访问即 ambiguous。
select 表达式支持 col（可带 qualifier）、literal（整数/文本/null）、exists 子查询；star:true 展开当前块 from 的未限定输出，star:alias 展开当前块指定侧，不能展开祖先块。输出列表允许同名列，返回数组列元数据及数组行，不能字典覆盖。显式 as 只改变输出标签，不进入同层 WHERE 命名空间。where 支持 eq、gt、and，遵循 SQLite NULL 逻辑。EXISTS 子查询最多两层，from 仅一表；先查本层，未限定名本层无候选才往外层找，遇到本层歧义就失败，不能继续外找；限定名找到最近同名别名后，缺列直接错误，不能跳到外层同名别名。绑定引用保存 query-block 路径、scope_depth 和物理侧列，USING 合并列另保存双侧来源及左侧取值规则。不能通过执行 SQL 后看结果列名来代替绑定。
